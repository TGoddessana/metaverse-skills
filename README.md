# metaverse-skills

실제 장소를 걸어 다닐 수 있는 3D 공간(three.js 웹페이지)으로 만들어 주는 Claude 스킬 모음입니다.

## metaverse-space-builder

"OO 공간을 메타버스로 구현해줘"라고 말하면 아래 순서로 진행합니다.

1. 장소 이름, 주소, 사진 유무를 묻기
2. 웹 검색과 후기로 크기, 구조, 재질, 가구 배치 파악
3. `space-spec.json` 설계도로 정리
4. three.js 한 장짜리 페이지로 제작 (PC: WASD + 마우스, 휴대폰: 조이스틱, 벽 충돌, 미니맵, 설명 표지)
5. 브라우저로 화면을 찍어 점검한 뒤 공유

웹에서 찾은 사진은 참고용으로만 쓰고, 사용자가 직접 찍은 사진만 질감으로 넣습니다.

## 설치

`metaverse-space-builder` 폴더를 Claude 스킬로 추가하면 됩니다.
